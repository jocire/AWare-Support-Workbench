# AWare Support Workbench

AWare Support Workbench is a focused support-engineering tool for private Engineer Sessions and request-scoped plugin isolation on real WordPress sites.

The plugin deliberately does not include broad Maintenance Scan/crawling or targeted evidence collection. Its job is to let an engineer reproduce the real issue with selected plugins removed only from that engineer's authenticated browser context.

See **Engineer Sessions**, **How Isolation Works**, **Safety Model**, **Testing**, and **Release Checklist**.
