# Installation

1. Install and activate AWare Support Workbench.
2. Confirm `wp-content/mu-plugins/aware-support-workbench-bootstrap.php` is created.
3. Open **Tools → Support Workbench**.
4. Confirm the Engineer Session state, plugin-isolation table, selection controls, and mode selector are visible.
5. Deactivate the plugin and verify the managed MU bootstrap is removed. Reactivate and verify it is recreated.
