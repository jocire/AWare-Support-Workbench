# Usage Guide

1. Open **Tools → Support Workbench**.
2. Select the active plugin(s) you want isolated in your browser.
3. Choose **Production Safe** or **Sandbox / Development**.
4. Start the Engineer Session.
5. Reproduce the affected frontend or wp-admin workflow normally in the same browser.
6. Return to Workbench, change the plugin set, and use **Update Engineer Session** as needed.
7. Use another browser/incognito window when you want to confirm normal production behavior remains unchanged.
8. Stop the Engineer Session when troubleshooting is complete.

Support Workbench does not crawl URLs or collect a separate evidence dashboard. The real affected workflow is the test surface.
